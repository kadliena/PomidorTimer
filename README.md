# Помидорковый таймер

## О проекте

«Помидорковый таймер» — веб-приложение для организации рабочего времени с использованием техники Pomodoro.

Приложение позволяет пользователю запускать рабочие интервалы, делать перерывы, настраивать продолжительность интервалов и отслеживать результаты текущего рабочего сеанса.

## Основной функционал

Приложение предусматривает:

- таймер интервалов работы и отдыха;
- запуск, паузу, продолжение и сброс таймера;
- автоматическое переключение между рабочими интервалами и перерывами;
- звуковые уведомления;
- настройки внешнего вида;
- статистику текущего сеанса;
- информационные разделы о технике Pomodoro;
- раздел часто задаваемых вопросов;
- советы по использованию техники Pomodoro.
