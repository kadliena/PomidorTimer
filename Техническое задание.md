# Техническое задание

## 1. Общие сведения

**Название проекта:** «Помидорковый таймер».

**Тип приложения:** веб-приложение.

**Назначение:** организация рабочего времени пользователя с использованием техники Pomodoro.

## 2. Цель проекта

Разработать веб-приложение, позволяющее планировать рабочие интервалы и перерывы, управлять таймером и отслеживать результаты текущего рабочего сеанса.

## 3. Функциональные требования

Приложение должно обеспечивать следующие возможности:

1. Отображение таймера рабочего интервала и перерыва.
2. Запуск, приостановку, продолжение и сброс таймера.
3. Автоматическое переключение между рабочими интервалами и перерывами.
4. Настройку продолжительности рабочих интервалов и отдыха.
5. Воспроизведение звуковых уведомлений по завершении интервала.
6. Настройку внешнего вида приложения.
7. Отображение статистики текущего рабочего сеанса.
8. Просмотр информационных материалов о технике Pomodoro.
9. Просмотр часто задаваемых вопросов и советов по использованию техники.

Регистрация пользователей и база данных не предусматриваются.

## 4. Технологический стек

Для разработки приложения планируется использовать:

- C#;
- .NET Framework 4.8;
- ASP.NET;
- HTML5;
- CSS3;
- JavaScript;
- Visual Studio 2026;
- Git и GitHub для управления версиями и совместной разработки.

## 5. Требования к интерфейсу

Интерфейс должен быть понятным и удобным для пользователя. Основные элементы управления таймером должны быть доступны с главной страницы. Приложение должно корректно отображаться в современном веб-браузере.

## 7. Результат разработки

Результатом должен стать работоспособный веб-сайт, позволяющий пользователю применять технику Pomodoro для организации рабочего времени без регистрации.

## Инструкция по запуску проекта

Для запуска веб-приложения необходимо установить Visual Studio 2026 с компонентами разработки ASP.NET и поддержку .NET Framework 4.8.

После получения исходного кода проекта необходимо выполнить следующие действия:

1. Открыть решение `PomidorTimerCode.sln` в Visual Studio 2026.
2. Убедиться, что в качестве запускаемого проекта выбран `PomidorTimerCode`.
3. Проверить, что целевая версия платформы — .NET Framework 4.8.
4. Запустить приложение клавишей `F5` или кнопкой запуска в Visual Studio.
5. Дождаться запуска локального веб-сервера и открытия приложения в браузере.

Для запуска приложения не требуется регистрация пользователя или подключение к базе данных.

Инструкция будет уточнена после создания базового проекта и проверки его запуска.
